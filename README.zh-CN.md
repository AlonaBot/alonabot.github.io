# AlonaBot 文档站

[English](README.md)

面向机器人主人和插件作者的 [AlonaBot](https://github.com/AlonaBot/AlonaBot) 文档，对应 Core **0.2.0** 与官方组件。

站点提供[简体中文](https://alonabot.github.io/docs/)与 [English](https://alonabot.github.io/docs/en/)。从[安装](https://alonabot.github.io/docs/docs/usage/install)或[第一个插件](https://alonabot.github.io/docs/docs/quick-start)开始。

本地编辑需要 Node.js 20 或更新版本：

```fish
npm ci
npm start
# 英文预览
npm run start:en
```

双语正文、检查与 Pages 部署见[站点维护](maintenance/site.md)。贡献流程见 [CONTRIBUTING.zh-CN.md](CONTRIBUTING.zh-CN.md)。文档采用 [AlonaBot MIT License](https://github.com/AlonaBot/AlonaBot/blob/main/LICENSE)。
