下面以已发布的 v0.2.0 官方 Adapter 为准。调用以运行实例实际报告的能力为准，具体平台动作仍受账号权限和协议端支持影响。

| --- | --- | --- |

## 插件怎么应对

平台缺少能力时返回 `UNSUPPORTED`；有明确替代行为时处理该错误，其他错误继续返回：

```go
_, err := c.Edit(ref, message.Text("Done."))
if errcode.Of(err) == errcode.Unsupported {
    return c.Reply("Done.")
}
return err
```

导入 `sdk/message` 与 `sdk/errcode`。`c.Stream` 已按编辑能力选择逐步编辑或结束后发送。媒体和节点读取可返回部分结果与错误，处理错误后再决定使用范围。

## 平台细节

- [Telegram](telegram.md)：long polling、代理、媒体、动作、菜单分域。
- [OneBot11](onebot11.md)：正反向 WS、多实例、共享媒体和 SnowLuma v2.4.2 空 `m_resid` 问题。

## 终端对话

开发终端支持文字、按钮编号和编辑；媒体显示为占位。接入真实平台后仍需验证平台渲染、权限与协议端行为。
