插件的代码在各平台上相同，但平台本身能做的事不一样，Adapter 的开发进度也不同。

## 对照表

| 功能 | Telegram | OneBot 11 |
| --- | --- | --- |
| 接收私聊、群聊消息 | ✅ | ✅ |
| 接收图片、文件 | ✅（不超过 20 MB） | ❌ |
| 发送文字 | ✅ | ❌ |
| 发送图片、文件、相册 | ✅ | ❌ |
| 引用回复 | ✅ | ❌ |
| 按钮 | ✅ | ❌ |
| 编辑已发出的消息 | ✅（仅文字） | ❌ |
| 流式输出 | ✅ | ❌ |
| 撤回消息 | ❌ | ❌ |
| 进群、退群事件 | ✅ | ✅ |
| 消息被编辑的事件 | ✅ | ❌ |
| 消息被撤回的事件 | ❌ | ✅ |
| 表情回应事件 | ✅ | ❌ |
| 群管理员、群主权限 | ✅ | ✅ |
| 语音、贴纸、动图 | ❌ | ❌ |

❌ 表示还没有实现，不代表平台本身做不到。

## 插件怎么应对

调用平台不支持的功能时，返回的错误码是 `UNSUPPORTED`。需要兼容多个平台的插件可以检查它，换一种方式：

```go
	_, err := c.Edit(ref, message.Text("Done."))
	if errcode.Of(err) == errcode.Unsupported {
		// 不能编辑，就再发一条
		return c.Reply("Done.")
	}
	return err
```

[流式输出](../advanced/media.md#流式输出)已经内置了这种处理：平台不能编辑消息时自动改成一次发完。

## 终端对话

`alonabot run` 的终端对话是开发用的，支持文字、按钮（输入 `#编号` 点击）和编辑（显示成一条带 `(edited)` 的新行）。图片等内容显示成 `[image]` 这样的占位。
