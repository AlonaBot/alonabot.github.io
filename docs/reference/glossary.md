---
title: 术语表
description: 文档里出现的名词。
---

| 名词 | 含义 |
| --- | --- |
| **Core** | 机器人的主程序，即 `alonabot` 命令。负责接收消息、找到对应的插件、检查权限、发送回复、管理所有组件 |
| **组件** | 可以单独安装的部分。有四种：插件、Adapter、Agent、WebUI |
| **插件** | 提供机器人功能的组件：命令、定时任务、页面等 |
| **Adapter** | 接入一个聊天平台的组件，如 Telegram Adapter |
| **Agent** | 提供 AI 对话的组件，也让其他插件能调用大模型 |
| **WebUI** | 浏览器里的管理界面 |
| **平台** | 聊天软件，如 Telegram、QQ |
| **机器人账号** | 机器人在某个平台上的一个账号。一个平台可以配置多个。文档和设置里也叫「实例」（instance） |
| **会话** | 一个聊天的地方：一个私聊、一个群，或者群里的一个话题 |
| **Handler** | 你写的处理函数。命令被调用、事件发生时由框架执行 |
| **Context** | Handler 的第一个参数 `c`，代表这一次调用。从它取得发消息的人、所在会话，用它回复 |
| **命令** | 以前缀（缺省 `/`）开头的消息，如 `/help` |
| **事件** | 平台上发生的事：有新消息、有人进群、按钮被点击等 |
| **消息链**（Chain） | 一条消息的内容，由若干片段组成 |
| **片段**（Segment） | 消息内容的一部分：一段文字、一张图片、一个 @ |
| **规则**（Rule） | 决定 Handler 要不要处理某条消息的函数 |
| **权限** | 决定谁能使用某个命令 |
| **机器人管理员** | 设置里 `admins` 列出的用户，能使用限定管理员的命令 |
| **管理 token** | 登录 WebUI 和使用管理命令的凭证。和机器人管理员是两回事 |
| **数据目录** | Core 保存所有设置和数据的目录，缺省是 `data/` |
| **配置项** | 插件留给机器人主人调整的选项，在 `config_schema.json` 里声明 |
| **密钥** | 标记了 `secret` 的配置项，如 API key。界面上不显示原值 |
| **配置文件**（profile） | 一组设置的名字。让不同的会话使用不同的设置 |
| **服务**（Service） | 插件提供给其他插件调用的功能 |
| **广播** | 插件发出的通知，其他插件可以订阅。不保证送达 |
| **工具**（Tool） | 允许 AI 在对话中调用的服务 |
| **Hook** | 在事件派发前，或本插件发送前后插入的逻辑 |
| **子插件** | 把一个插件的代码按功能分成几部分的方式 |
| **能力**（Capability） | 平台支持的功能，如「能编辑消息」「能发按钮」 |
| **终端对话** | `alonabot run` 时在终端里直接和机器人对话的功能，开发用 |
| **安装包** | `alonabot pack` 打出的压缩包，用来安装组件 |
| **代次**（generation） | 一个组件每次安装、更新或修改配置后形成的一个版本状态，包括程序、配置和数据库。更新失败时可以退回上一个代次 |
| **Session** | 一个组件进程和 Core 之间的一次连接。组件每次启动建立一个新的 |
