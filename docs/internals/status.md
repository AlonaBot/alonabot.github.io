AlonaBot 目前是 **0.1-beta**。主要功能已经可用，接口在正式发布前还可能调整。

## 已经可用

**写插件**

- 命令：参数、别名、分组、权限
- 文本匹配、事件、规则
- 回复文字、图片、文件、按钮；编辑消息；流式输出
- 配置项、密钥、按会话设置
- 键值存储、SQLite 数据库、更新失败自动恢复
- 多轮对话
- 定时任务、用户创建的任务
- 插件之间的服务调用和广播
- 调用大模型
- HTTP 接口和插件页面
- 多语言
- 用 `plugintest` 测试

**运行和管理**

- 安装、更新、退回、卸载组件
- 修改代码后自动重新加载
- 终端对话
- 日志、诊断包
- 安装脚本、Docker 镜像

**官方组件**

- Telegram Adapter
- Agent：对话、工具调用与确认、MCP、记忆、技能
- WebUI
- `/help` 插件

## 还在开发

- **OneBot 11**：只能接收消息，不能发送。
- **Telegram**：语音、贴纸、动图；撤回消息；命令菜单。
- **WebUI**：部分页面还不完整。
- **撤回消息**：SDK 有接口，但还没有平台实现它。

各平台的具体情况见[平台功能对照](../usage/platforms.md)。

## 在哪些系统上测试过

目前主要在 macOS（Apple 芯片）上开发和运行。Linux 和 Windows 的安装包可以正常构建，但实际运行的测试还不充分。在这些系统上遇到问题请反馈。

Telegram 的发送等功能主要用本地的模拟服务测试，OneBot 11 同样如此。

## 兼容性

0.1 正式发布之前，SDK 的接口、配置文件的格式、数据目录的结构都可能有不兼容的改动。现在写的插件在升级后可能需要调整。
