---
title: Test plugins on a platform
description: Connect a plugin under development to a real Telegram bot.
---

Run the todo plugin with a configured Telegram account to test real messages while retaining hot reload.

## CLI setup

Install the [official CLI](../usage/install.md#manual) and Go 1.27.1 to compile and run the plugin.

Run from the todo project directory and keep using its `./data` directory.

## 1. Create a bot

Find [@BotFather](https://t.me/BotFather) on Telegram, send `/newbot`, and follow the naming prompts. It returns a token such as `123456:ABC-DEF...`.

## 2. Configure the account

Core settings are in `data/core_config.json`, generated by the first `alonabot run`. Add `adapters`:

```json title="data/core_config.json"
{
  "adapters": {
    "telegram": {
      "instances": {
        "main": { "token": "${TELEGRAM_BOT_TOKEN}" }
      }
    }
  }
}
```

Keep the existing fields and add this `adapters` section. `main` is the account name. `${TELEGRAM_BOT_TOKEN}` reads the token from the environment.

## 3. Run

```fish
set -gx TELEGRAM_BOT_TOKEN '123456:ABC-DEF...'
alonabot run
```

Core detects the Telegram account and enables its Adapter at startup. If absent, it downloads and installs it from the official repository, requiring internet access on first use. [Reinstall manually](../usage/install.md#install-official-components) if you previously uninstalled the Adapter. Terminal chat no longer opens automatically when platform accounts are configured.

Send `/todo add buy milk` to your bot on Telegram to receive `Added: buy milk`. Code changes still reload automatically.

:::tip Trouble connecting to Telegram?
Configure a proxy in `core_config.json` and let the account use it:

```json
{
  "proxy": "http://127.0.0.1:7890",
  "adapters": {
    "telegram": {
      "instances": {
        "main": { "token": "${TELEGRAM_BOT_TOKEN}", "proxy_mode": "core" }
      }
    }
  }
}
```
:::

## 4. Set yourself as an administrator

Commands with `sdk.Admin` require a bot administrator. Install and enable the builtin plugin following [Telegram setup](telegram.md#connect), then send `/whoami` on Telegram to get your user identifier:

```text
telegram:123456789
```

Add it to `admins` in `core_config.json`:

```json
{
  "admins": ["telegram:123456789"]
}
```

Saving takes effect immediately, without restarting.

## Keep terminal chat open

Add `--console` to use terminal chat alongside Telegram:

```sh
alonabot run --console
```

## Platform differences

The same plugin code runs across platforms, while available operations vary. Calling an unavailable operation, such as editing a sent message, returns `UNSUPPORTED`. [Query account capabilities](index.md#query-account-capabilities) to inspect available operations.
