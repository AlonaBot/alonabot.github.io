Store user-facing text in locale dictionaries and resolve it at the point of use.

## Dictionaries and placeholders

```json title="i18n/en-US.json"
{
  "messages": {
    "added": "Added: {text}",
    "empty": "Nothing to do.",
    "full": "Your list is full ({limit} items)."
  }
}
```

```json title="i18n/zh-CN.json"
{
  "messages": {
    "added": "已添加：{text}",
    "empty": "没有待办。",
    "full": "清单已满（{limit} 条）。"
  }
}
```

```go
func add(c *sdk.Context, text string) error {
	return c.Reply(c.T("added", "text", text))
}

func list(c *sdk.Context) error {
	return c.Reply(c.T("empty"))
}
```

The Chinese dictionary is an example of a second language. Placeholder arguments are alternating string names and string values:

```go
c.T("full", "limit", fmt.Sprint(limit))
```

## Locale selection

Core considers the platform user's locale, the configured default_locale and en-US. Messages need an en-US source entry; other locales can translate a subset. Missing translations use the available source entry.

## Build checks

check/build validate literal keys and placeholder names against en-US and check other locales for extra keys or incompatible placeholders. Dynamic keys are resolved at runtime; missing entries log a warning and preserve the key or placeholder text.

## Other translated content

```json title="i18n/zh-CN.json"
{
  "messages": {
    "added": "已添加：{text}"
  },
  "commands": {
    "todo add": { "description": "添加一条待办" }
  },
  "config": {
    "limit": { "description": "每人最多几条", "hint": "超过后不能再添加" }
  },
  "pages": {
    "/page": "待办"
  }
}
```

| Node | English source |
| --- | --- |
| messages | `i18n/en-US.json` |
| commands | `.Description(...)`, canonical full command path |
| config | `config_schema.json` |
| pages | `.Page(...)`, keyed by HTTP path |

Descriptions are English in code/schema; locale files override them. Command-only locale files can omit messages. Command paths must match a registered command that has an English description.

## Background work

```go
text := sdk.T(ctx, "added", "text", item)
```

`sdk.T` uses the bound Session's language context or bot default when no user locale exists. Logs and error strings stay English; user replies are localized.
