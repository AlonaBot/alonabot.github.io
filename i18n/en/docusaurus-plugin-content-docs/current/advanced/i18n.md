Store user-facing text in language files under `i18n/`, then retrieve it in the user's language.

## Language files and placeholders

```json title="i18n/en-US.json"
{
  "messages": {
    "added": "Added: {text}",
    "empty": "Nothing to do.",
    "full": "Your list is full ({limit} items)."
  }
}
```

```json title="i18n/zh-CN.json"
{
  "messages": {
    "added": "已添加：{text}",
    "empty": "没有待办。",
    "full": "清单已满（{limit} 条）。"
  }
}
```

Use `c.T` in code:

```go
func add(c *sdk.Context, text string) error {
	return c.Reply(c.T("added", "text", text))
}

func list(c *sdk.Context) error {
	return c.Reply(c.T("empty"))
}
```

```text
> /todo add 买牛奶
已添加：买牛奶
```

The first argument to `c.T` is the key. Follow it with placeholder-name and value pairs:

```go
c.T("full", "limit", fmt.Sprint(limit))
```

Placeholder values are strings.

## Language selection and fallback

The framework selects a language in this order:

1. The user's platform language, when available.
2. Core's `default_locale`, configured by the bot owner.
3. English, `en-US`.

Missing keys fall back to English. **`en-US.json` must contain every key**; other languages can be partial.

## Build-time validation

`alonabot check` and `alonabot build` validate `c.T` calls:

- A missing key in `en-US.json` causes an error.
- Mismatched placeholder names cause an error.
- Placeholder differences or extra keys in other languages cause an error.

Use literal strings for keys and placeholder names. Dynamically computed keys cannot be checked.

## Other translated content

Alongside `messages`, the same file can translate:

```json title="i18n/zh-CN.json"
{
  "messages": {
    "added": "已添加：{text}"
  },
  "commands": {
    "todo add": { "description": "添加一条待办" }
  },
  "config": {
    "limit": { "description": "每人最多几条", "hint": "超过后不能再添加" }
  },
  "pages": {
    "/page": "待办"
  }
}
```

| Node | Translated content | English source |
| --- | --- | --- |
| `messages` | Replies to users | `en-US.json` |
| `commands` | Command list descriptions | `.Description(...)` in code |
| `config` | Configuration labels and descriptions | `plugin_config_schema.json` |
| `pages` | Plugin page titles | `.Page(...)` in code |

## Background translation

Use `sdk.T` without a call context, such as in background goroutines or HTTP callbacks. It uses the bot's default language:

```go
text := sdk.T(ctx, "added", "text", item)
```

## Language conventions

| Content | Language |
| --- | --- |
| User replies | User's language, stored in `i18n/` |
| Logs | English |
| Returned `error` text | English |
| Command descriptions, configuration descriptions, and page titles in code | English, with translations in `i18n/` |

English logs and errors help developers and bot owners search for troubleshooting information.
