## Send media

Use an HTTPS URL when available:

```go
return c.Reply("Here it is", message.ImageURL("https://example.com/chart.png"))
```

For generated bytes, import `sdk/media`:

```go
import "github.com/AlonaBot/AlonaBot/sdk/media"

func export(c *sdk.Context) error {
	file, err := media.File(c, []byte("buy milk\ncall mom\n"), "todos.txt", "text/plain")
	if err != nil {
		return err
	}
	return c.Reply("Your list", file)
}
```

`media.Image(c, data)` and `media.Video(c, data)` follow the same pattern. Small content is inline; larger content is uploaded. Stream large inputs through Upload:

```go
	f, err := os.Open(path)
	if err != nil {
		return err
	}
	defer f.Close()

	ref, err := media.Upload(c, f, "application/zip")
	if err != nil {
		return err
	}
	return c.Reply("Backup", message.File(ref.Source(), "backup.zip"))
```

Import `os`. Use `ref.Source()` to construct a media segment.

## Read incoming images

```go
	p.Command("size").Handle(func(c *sdk.Context, img *message.ImageSegment) error {
		r, err := media.Open(c, img.Source)
		if err != nil {
			return err
		}
		defer r.Close()

		data, err := io.ReadAll(r)
		if err != nil {
			return err
		}
		return c.Reply(fmt.Sprintf("%d bytes", len(data)))
	})
```

Import `io`, `fmt`, `sdk/message` and `sdk/media`. Close the reader when finished. To total image sizes in ordinary messages, inspect their chain. Also import `errors`; `errors.Join` preserves both read and close failures:

```go
	p.On(sdk.MessageCreated).Handle(func(c *sdk.Context, e *message.CreatedPayload) error {
		var total int64
		for _, seg := range e.Chain {
			if img, ok := seg.(message.ImageSegment); ok {
				r, err := media.Open(c, img.Source)
				if err != nil {
					return err
				}
				n, readErr := io.Copy(io.Discard, r)
				closeErr := r.Close()
				if err := errors.Join(readErr, closeErr); err != nil {
					return err
				}
				total += n
			}
		}
		if total == 0 {
			return nil
		}
		return c.Reply(fmt.Sprintf("Images: %d bytes", total))
	})
```

## Editing and deleting

```go
func work(c *sdk.Context) error {
	sent, err := c.Send(message.Text("Working..."))
	if err != nil {
		return err
	}

	_, err = c.Edit(sent.Ref(), message.Text("Done."))
	return err
}
```

Delete a message using its receipt:

```go
_, err = c.Delete(sent.Ref())
```

A message handle is a string you can store. Reference the inbound message with:

```go
return c.Reply("Got it", message.Quote(c.Event().Ref()))
```

Telegram supports text plus optional buttons for edits. Both official adapters support deletion, subject to platform permissions. Unsupported operations return `UNSUPPORTED`.

## Streaming

```go
func story(c *sdk.Context) error {
	parts := []string{"Once upon a time, ", "there was a bot. ", "The end."}
	i := 0
	_, err := c.Stream(func(ctx context.Context) (string, error) {
		if i == len(parts) {
			return "", io.EOF
		}
		part := parts[i]
		i++
		return part, nil
	})
	return err
}
```

Import `context` and `io`. Each call returns incremental text; `io.EOF` ends the stream and may accompany a final chunk. With editing support, Core sends and throttles edits, starting a new message at the instance text limit. Without edits, it sends once after normal completion. Failed streams retain receipts for content already sent; buffered output on a non-editing platform is not published on input failure.

## Other chats and instances

```go
_, err := c.SendTo("telegram:-100123456", message.Text("Hello"))
```

```go
_, err := c.SendTo(session, message.Text("Hello"), sdk.Via("main"))
```

Save `c.Session()` or construct a session with `message.SID`. `sdk.Via` chooses an instance. Explicit outbound sends follow the plugin's allowed-instance policy; replies to the original trusted inbound target use reply permission.

## References and recursive nodes

On OneBot11, `c.ReadNodes(forward)` resolves a ForwardSegment into recursive `[]message.ForwardItem`, preserving authors, timestamps and authorized media. Continue through nested ForwardSegment.Items. In background work use `sdk.ReadNodes(ctx, session, forward, sdk.Via(instance))`. Preserve partial nodes alongside errors and handle the error before deciding how to use them. See [OneBot11](../usage/onebot11.md#forward-nodes) for reference queries and the SnowLuma issue.

`media.Open` accepts managed or platform sources. An HTTPS URL source returns `INVALID_ARGUMENT`; outgoing URLs are downloaded by the platform. Core supplies trusted source MIME to adapters, including GIF metadata for Telegram.
