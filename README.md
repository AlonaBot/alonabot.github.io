# AlonaBot documentation

[简体中文](README.zh-CN.md)

User and plugin-developer guides for [AlonaBot](https://github.com/AlonaBot/AlonaBot), covering Core **0.2.0** and the official components.

Read the site in [English](https://alonabot.github.io/docs/en/) or [简体中文](https://alonabot.github.io/docs/). Start with [installation](https://alonabot.github.io/docs/en/docs/usage/install) or [your first plugin](https://alonabot.github.io/docs/en/docs/quick-start).

To edit locally, use Node.js 20 or later:

```fish
npm ci
npm start
# English preview
npm run start:en
```

See [site maintenance (简体中文)](maintenance/site.md) for bilingual content, validation and Pages deployment. Contributions follow [CONTRIBUTING.md](CONTRIBUTING.md). Documentation is provided under the [AlonaBot MIT License](https://github.com/AlonaBot/AlonaBot/blob/main/LICENSE).
